# ClosingView

SaaS de productivité pour closers et équipes commerciales — suivi des deals, objectifs et performances.

## Stack

React (Vite) + TypeScript + shadcn/ui + Tailwind CSS, backend Supabase.

## Démarrage

```bash
npm install
npm run dev
```

Nécessite un fichier `.env` avec `VITE_SUPABASE_URL` et `VITE_SUPABASE_PUBLISHABLE_KEY`.
